# Code of conduct

## The short version

Be decent. Assume good faith. Critique the work, not the person.

## Scope

This applies in issues, pull requests, discussions, and anywhere else someone
is representing the project.

## Not acceptable

Harassment, personal attacks, discriminatory or sexualised language, sustained
disruption, publishing someone's private information without permission.

## Enforcement

Report to `quocvinh.hnguyen@gmail.com`. Reports stay private. As a
single-maintainer project the response is simply the maintainer's judgement —
usually a warning, and blocking for anything repeated or severe.

This is a deliberately short policy for a small project. It is adapted in
spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
whose full text is a good reference if you want the formal version.
